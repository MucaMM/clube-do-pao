CLUBE DO PAO - CONFIGURACAO DO SUPABASE

1) O projeto já está configurado no site com a URL e a Publishable Key fornecidas.
2) No Supabase, execute o arquivo supabase_patch.sql no SQL Editor.
3) Para criar o primeiro administrador:
   - Abra conta.html ou o próprio site e crie uma conta com o e-mail que será usado como administrador.
   - Depois que a conta for criada, no SQL Editor execute:

   update public.perfis
   set role = 'admin'
   where id = (select id from auth.users where email = 'SEU_EMAIL_AQUI');

   Substitua SEU_EMAIL_AQUI pelo e-mail da conta.

4) O painel administrativo está em admin.html e agora exige uma conta com role = admin.
5) Não coloque a Database Password nem a service_role/secret key no site.
6) A tela "Seus dados" não pede CPF nem e-mail como dado pessoal. O e-mail/senha são usados apenas para a conta de acesso.

OBSERVACAO SOBRE CONFIRMACAO DE EMAIL
Se o Supabase estiver configurado para exigir confirmação de e-mail, o cadastro pode pedir que o cliente confirme o endereço antes de entrar. Isso é normal e pode ser mantido em produção.
